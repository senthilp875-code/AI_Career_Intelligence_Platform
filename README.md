# AI Career Intelligence Platform

## Vision

AI Career Intelligence Platform is an AI-powered web application that helps students and job seekers analyze resumes, identify skill gaps, recommend jobs, estimate salaries, and prepare for interviews.

## Features

- Resume Analysis
- Skill Gap Detection
- ATS Resume Score
- AI Job Recommendation
- Salary Prediction
- Learning Roadmap
- Recruiter Dashboard
- Analytics Dashboard
